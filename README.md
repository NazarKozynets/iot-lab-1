# Лабораторна робота №1. Основи роботи з Node-RED

## Запуск

У цій папці відкрийте термінал і виконайте:

```powershell
npm.cmd ci
npm.cmd start
```

Редактор: [http://127.0.0.1:1880](http://127.0.0.1:1880).
Панель: [http://127.0.0.1:1880/ui](http://127.0.0.1:1880/ui).

Якщо Node-RED уже налаштовано, встановіть у його палітрі `node-red-dashboard`, імпортуйте `flows.json` через **Import** і натисніть **Deploy**.

## Що перевірити

- **Вправи 2.2–2.6.** Увімкніть панель Debug. Кнопка біля `Timestamp вручну` надсилає позначку часу. Ще два Inject кожні 5 секунд надсилають позначку часу та текст варіанта з темою `topic1`.
- **Основний потік.** На панелі кожні 5 секунд оновлюється дата, а число прописом змінюється щосекунди. `Debug1` вимкнено. Його можна ввімкнути, щоб бачити послідовність у редакторі.
- **Температура.** Змініть положення повзунка і відпустіть його. Стрілка шкали й кольоровий індикатор оновляться, а браузер отримає число для озвучення. Для звуку потрібна активна вкладка з панеллю та доступний голос синтезу мовлення.

У потоці задано варіант №3: від 5 до 70 °C включно відповідає нормі. Перша закладка Dashboard має назву «Козинець Назарій».

JavaScript у вузлах Function зберігається в полі `func` файлу `flows.json`. Щоб перевірити форматування файлів, виконайте `npm.cmd run format:check`.
